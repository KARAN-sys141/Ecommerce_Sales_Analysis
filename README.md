# Ecommerce_Sales_Analysis

This Dashboard gives a clear view of how sales are performing across platforms like Jiomart,Swiggy_instamart and Blinkit. It helps track Customer orders,delivery performance,ratings,refunds and overall revenue.

This helps in many Questions like,

•Which Platform has the most orders
•How many deliveries were delayed
•How many refunds were requested
•Average order value and customer rating
